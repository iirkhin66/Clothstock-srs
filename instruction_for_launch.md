# Руководство по развертыванию и запуску ClothStock

## 1. Системные требования
Для запуска приложения потребуются:
* **Java Development Kit (JDK):** Версия 17 или выше.
* **СУБД PostgreSQL:** Версия 14 или выше.
* **Среда разработки (IDE):** IntelliJ IDEA (или любая другая удобная среда разработки, например Eclipse или VS Code).

## 2. Подготовка базы данных
1. Откройте инструмент управления СУБД **pgAdmin** (или DBeaver / консоль PostgreSQL).
2. Создайте новую пустую базу данных с точным названием `clothstock`.

> ⚠️ **Важно:** Вручную создавать таблицы не нужно! Система объектно-реляционного отображения (через Hibernate) сама автоматически сгенерирует и обновит всю необходимую структуру таблиц в базе данных при первом запуске приложения.

3. Проверьте файл настроек проекта по пути: `src/main/resources/application.properties`. Убедитесь, что логин и пароль от локальной базы данных совпадают с вашими учетными данными. По умолчанию в конфигурации прописаны:
   * **Логин:** `postgres`
   * **Пароль:** `1234`

## 3. Запуск веб-приложения
1. Откройте корневую папку проекта в **IntelliJ IDEA**.
2. Дождитесь, пока сборщик проектов **Maven** скачает все необходимые зависимости (в правом или нижнем углу экрана полностью завершится процесс фоновой индексации).
3. Найдите главный класс приложения (класс, содержащий метод `main` и аннотацию `@SpringBootApplication`) и нажмите зеленую кнопку **Run** (Запуск) для старта встроенного сервера приложений.

## 4. Доступ к системе
Согласно техническим требованиям безопасности спецификации (NFR-03), приложение использует защищенный протокол **HTTPS** и разворачивается на порту **8443**.

1. Откройте ваш веб-браузер и перейдите по прямой ссылке: [https://localhost:8443/login](https://localhost:8443/login)
2. При первом переходе браузер выдаст стандартное предупреждение о самоподписанном сертификате безопасности (Защита подключения). Нажмите кнопку **«Дополнительно»** (или «Advanced»), а затем выберите пункт **«Перейти на сайт localhost (небезопасно)»**.

## 5. Демонстрационные учетные записи
При первом запуске система автоматически инициализирует базу данных начальными записями и создает трех пользователей для полноценного тестирования ролевой модели доступа.

**Общий пароль для всех аккаунтов:** `1234`

| Роль пользователя | Логин (Email) | Доступный функционал в интерфейсе (UI) |
| :--- | :--- | :--- |
| **Менеджер** | `manager@vstu.ru` | **Полный доступ:** управление каталогом товаров (добавление, удаление), изменение параметров и состояний позиций («На складе», «В торговом зале», «Продан»), а также просмотр и выгрузка отчетов о прибыли и убытках в форматах PDF / CSV. |
| **Кассир** | `cashier@vstu.ru` | **Урезанный доступ:** доступен только поиск товаров по названию или артикулу, просмотр актуального состояния и остатка. Все элементы управления (кнопки редактирования, удаления и управления отчетами) скрыты от пользователя согласно критерию приёмки AC-04. |
| **Администратор** | `admin@vstu.ru` | **Доступ к панели администрирования:** просмотр служебной страницы управления учетными записями сотрудников организации. |
