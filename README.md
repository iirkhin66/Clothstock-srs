## Результаты выполненных заданий

### Задача 1 — Концепция программного продукта

Разработана концепция системы **ClothStock** — веб-приложения для учёта товаров небольшого магазина одежды.

- Описана проблема: менеджеры ведут учёт остатков вручную в Excel, что приводит к ошибкам и потере продаж из-за незамеченного дефицита.
- Определены заинтересованные лица и назначение системы.
- Построена контекстная диаграмма: 3 роли пользователей + 3 внешних сервиса.
- Проведён сравнительный анализ 3 конкурентов одного сегмента (XS–S): **Shopify POS**, **ЕКАМ**, **МойСклад** с приоритетами e/u/d.
- Сформулировано описание продукта по шаблону Мура.

### Задача 2 — Моделирование пользовательских требований

Выделены 3 роли пользователей методом опорных точек зрения:

| Роль | Категория | Потребности |
|------|-----------|-------------|
| Кассир | U (обычный) | Поиск товара, просмотр состояния и остатка |
| Менеджер | Р (продвинутый) | Управление товарами, состоянием, отчёты о прибыли/убытках |
| Администратор | XS (корпоративный) | Управление учётными записями и правами доступа |

Составлены 5 вариантов использования (Use Case):

| UC | Название | Актор |
|----|----------|-------|
| UC-01 | Управление товарами (добавление / удаление) | Менеджер |
| UC-02 | Изменение параметров товара | Менеджер |
| UC-03 | Управление состоянием товара (склад / зал / продан) | Менеджер |
| UC-04 | Управление учётными записями сотрудников | Администратор |
| UC-05 | Расчёт прибыли и убытков за период | Менеджер / Администратор |

### Задача 3 — Систематизация требований

Составлен структурированный список требований комбинированным методом: матрица классификации + диаграмма Венна.

**Матрица классификации** (4 категории × 3 роли, 14 функциональных требований FR-01…FR-14).

**Диаграмма Венна**: выявлены 2 пересекающихся требования (общих для Кассира и Менеджера):
- FR-01 — Поиск товара
- FR-05 — Просмотр состояния и остатка товара

Все требования атомарны, однозначны и проверяемы (правило «один глагол»). Указаны приоритеты MoSCoW.

### Задача 4 — Спецификация требований (SRS)

Составлена итоговая SRS по стандарту **IEEE 830 / ISO 29148**, интегрирующая результаты задач 1–3.
